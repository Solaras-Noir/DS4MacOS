## Questions for the architect

1. Rumble does nothing over USB (strong 200 and 255/255 tried; writes succeed). Is a further flag or field
   needed? Lightbar, trigger and player LED work with the same builder. Needed: a corrected builder (M1).
2. `swift test` cannot run: only the Command Line Tools are installed, so `XCTest` is missing. Install full
   Xcode, or another way? Meanwhile the fixture test is unverified; I committed docs and fixtures without a
   green local test run, so rely on the macOS CI job for that.
3. Fallout 4 ignores the keyboard once it has seen a controller, even after the controller is seized. Seizing
   before the game boots works. Should the app be responsible for seize-before-launch ordering?
4. The XInput stub crashes the game at launch. Likely cause: ordinals (the stub's named exports are at 93-99,
   Microsoft's xinput1_3 uses different ones). Please confirm the ordinal table, fix and rebuild the stub in
   a cloud session. A retest on a clean launch (no F4SE plugins) would rule the plugins out.
